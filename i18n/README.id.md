# Terjemahan KomiKita

String asli berada di `src/commonMain/moko-resources/base/`, Bahasa Indonesia di `.../in/`. Nama produk KomiKita tidak diterjemahkan. Terjemahan upstream dipertahankan. Kirim perubahan KomiKita melalui pull request pada repositori ini.

Dokumentasi proyek menggunakan bahasa Inggris secara bawaan, dengan tautan Bahasa Indonesia di bagian atas setiap panduan terjemahan. Lihat [indeks dokumentasi](../docs/id/README.md). Perbarui kedua versi saat mengubah isi panduan.

Deskripsi toko dikelola terpisah di `fastlane/metadata/android/en-US/` untuk bahasa Inggris dan `fastlane/metadata/android/id/` untuk Bahasa Indonesia. Direktori resource aplikasi `in` dan locale toko `id` sama-sama merujuk pada Bahasa Indonesia.
