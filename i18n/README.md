# KomiKita translations

English app strings are in `src/commonMain/moko-resources/base/`; Indonesian strings are in `src/commonMain/moko-resources/in/`. Do not translate the KomiKita product name. Existing upstream translations are retained. Submit KomiKita translation changes through a pull request in this repository.

Project documentation uses English by default, with an Indonesian language link at the top of each translated guide. See the [documentation index](../docs/README.md). Update both versions when changing their content.

Store descriptions are maintained separately under `fastlane/metadata/android/en-US/` for English and `fastlane/metadata/android/id/` for Indonesian. The app's `in` resource directory and the store's `id` locale both refer to Bahasa Indonesia.
