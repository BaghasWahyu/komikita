# Kebijakan Privasi KomiKita

KomiKita menyimpan perpustakaan, progres baca, preferensi, dan kredensial tracker pada perangkat. Backup dibuat di lokasi pilihan pengguna. Perlakukan file backup sebagai data pribadi.

Build bawaan tidak menyertakan Firebase Analytics atau Crashlytics. Build distributor yang menyertakan telemetry mengikuti pilihan persetujuan di pengaturan privasi.

Sumber konten, ekstensi yang dipasang, tracker, dan penyedia DNS menerima permintaan yang diperlukan untuk fitur terkait. Layanan tersebut memiliki kebijakan masing-masing.

Updater bawaan dinonaktifkan. Build dengan updater aktif menghubungi GitHub Releases KomiKita.

Fitur sembunyikan mengatur visibilitas antarmuka dan tidak mengenkripsi data. Kunci aplikasi dapat diatur terpisah pada pengaturan keamanan.

Pertanyaan proyek dapat disampaikan melalui [Issues KomiKita](https://github.com/BaghasWahyu/komikita/issues) tanpa token, password, atau data pribadi.
