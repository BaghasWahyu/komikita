# KomiKita privacy policy

KomiKita stores your library, reading progress, preferences, and tracker credentials on your device. Backups are created in a location you choose. Treat backup files as personal data.

Default builds do not include Firebase Analytics or Crashlytics. Distributor builds that include telemetry follow the consent choices in privacy settings.

Content sources, installed extensions, trackers, and DNS providers receive the requests needed for their respective features. These services have their own privacy policies.

APKs built by the GitHub release workflow, including FOSS, enable the built-in app updater. These builds contact GitHub to check KomiKita Releases automatically while the app is in use and when you check manually. Downloading an update also requests its APK from GitHub. Local and CI builds keep the updater disabled unless explicitly enabled.

Hiding features control visibility in the interface and do not encrypt data. App locking can be configured separately in security settings.

Project questions can be submitted through [KomiKita Issues](https://github.com/BaghasWahyu/komikita/issues). Do not include tokens, passwords, or personal data.
